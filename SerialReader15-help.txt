Communication:
= = = = = = = =
Program was created for devices what can communicate with PC OS protocol RS232,
so for communication between personal computers
with connectors RS232 or USB converters to RS232
and devices like microcomputers Arduinos or Espressif 
and their data modules for example.

Basic RS232 commands:
= = = = = = = = = = =
This commans are readable in program SerialReader versions 12 to 15 .
They are suitable for devices with Arduinos or with ESP-NOW system master and slaves

Command	Answer
- - - - - - - -
(Cr is carriage return, LF is Line Feed)
A	*A,400,#,CRLF   number is readed analog data example
B	*B,399,299,199,099,#,CRLF	
C	*C,401,etc.#,CRLF
D	neither realised nor used
E20	*P,20,400,500,100,#,CRLF = returned all parameters	
	   20, data time step in mikroseconds
P	*P,20,300,500,10,#,CRLF = read parameters

Note:
- - - 
All this commands can product Arduino with sensores
with my sketch RF_433MHz_SRX882_BME280_receiver_2.ino for examle

Simply manual how to use SerialReader15
= = = = = = = = = = = = = = = = = = = = 

Main(home) window
- - - - - - - - -
- after main(home) window is on and OK, push Device Set Button
- or Com Button, if you are not sure if your com port is set well
- Open Port window will be shown

Com window
- - - - - -
- push Open button
- if handle of predefined com port will set on, push Purge button and purge this comm port
- choose Device Par button and Osc Par window will be shown

Device Set window
- - - - - - - - -
- choose Q command from Call combobox and push Call button
- if answer will be OK and green round shape light will be on, you can continue with next parameters
- for example choose G Y Led from Call combobox and push Call button
- yellow led on your device (if is installed) will light on
- choose I command from Serial Commands combobox
- push Read button and wait  for answer in Answer or Result field
- if your asked device is on, the one will be confirmed
- or you will be asked to accept it
- or choose K command from Serial Commands combobox
- choose nr of asked device from device combobox
- push Set button and wait  for answer in Answer or Result field
- when this answer will repeat your slave device number, this one is on-line
- if your choosed device is on, it will be confirmed, else zero will be in answer
- push Read Par button to read pre-set parameters for Measure windows
- when your device is connected and it is on,
- push Data button to read data from your device via command A to be sure your device is measured OK 

Measure window
- - - - - - - -
- choose your task from listbox with tasks
- choose plotter type from plotter combobox A or B (more quick when data reading)
- if you need record of data, cross Record checkbox, New file button will be wisible
- occasionally write note of you to Note field
- press New file button to set the header of this new file what will be used for next data registration
- press Graph Par button to choose the suitable parameters for time and data axes
- press Graph and  Graph window will be shown

Grapf window
- - - - - - -
- set in Radiobutton Time axe for the type of graph time axe shift 
  when this time will be on the end of time range
- see and follow your measuring data, then press Stop button
- after all measuring ends, press Task button
- confirm if you want to save your data or on your hard disc
  or into databox for next analysation in tabs or graphs.
- press Menu button and Menu window will shown

Menu window
- - - - - -
- clik on the column with data
- choose Tab Par or Graph Par
- set parameters for table or graph
- click on the Table or Graph Image buttons
